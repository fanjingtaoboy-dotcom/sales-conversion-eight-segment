# 回归检查清单

作者：范范之辈

每次更新 skill 后，用这份清单判断是否变得更好，而不是只变得更长。

## Trigger Quality

- 用户说“报名、成交、续报、升单、咨询、预约诊断、报价、优惠、赠品、顾虑、案例”时，应能触发本 skill。
- 用户只问教学交付结构时，应建议使用课程七段，而不是硬套销讲八段。
- 用户给完整课程逐字稿时，应先切教学/销讲边界。
- 用户给训练营、福利课或多份同营逐字稿时，应识别多波次销讲，而不是强行找一个连续销讲段。
- 用户提到定金、锁价、插班、助教教报名、报名播报时，应触发行动路径和训练营波次检查。
- 用户提到58元、几十元、学费全返、付费占位、赠书赠工具、包邮时，应触发低客单免费入口检查。
- 用户提到0元表单、免费营、结缘营、福利课、低价体验转近3000元/几千元系统班时，应触发高客单免费入口检查。
- 用户提到一阶转二阶、筑基营转进阶营、基础班转进阶班、老学员续报/升单时，应触发转阶进阶销讲检查。
- 用户要求从复盘讨论、改稿反馈、真实案例中“提炼原则/优化skill/沉淀方法”时，应触发结构原理提炼检查。

## Diagnosis Quality

- 信息不足时，是否先判断是“直接做、暂判、还是先问”。
- 正式评分/完整改稿缺关键项时，是否只追问 3-5 个阻断问题。
- 快速诊断时，是否先给有用暂判，再列补充问题。
- 是否先建立学员转化分析卡。
- 对训练营稿，是否先输出销讲波次图：教学主链、销讲桥接、明确销讲、助教操作、作业收尾。
- 是否标注资料来源：用户提供、原稿证据、合理推断、暂缺。
- 是否判断价格档位和转化目标是否匹配。
- 对0元/免费入口转几十元低客单稿，是否先判断低价动作、付款性质、返还规则、赠品领取、助教操作和名额边界。
- 对0元/免费入口转高客单稿，是否先判断入口热度、免费体验深度、信任缺口、服务系统、风险逆转和证据矩阵。
- 对转阶进阶稿，是否先判断前一阶段已交付能力、下一阶段未解决缺口、用户认可的方案标准和产品承接证据。
- 是否检查问题唤醒的递进收口：泛共识问题 -> 专业学习问题 -> 真实应用/结果问题。
- 是否检查方案承接是“先标准后产品”，而不是从问题直接跳课程名。
- 是否检查主目标人群和次目标人群的取舍，避免多类人群平均铺开导致主线稀释。
- 是否检查模块价值下沉：模块/服务 -> 解决的问题 -> 交付机制 -> 学员结果感。
- 当用户要求提炼 skill 能力时，是否先输出“原理 -> 原则 -> 方法 -> 检查项 -> 脱敏样例”，而不是先复述具体案例。
- 是否把具体行业信息降级为样例或评测素材，避免进入核心规则。
- 是否说明每条新规则增强的是哪一段、哪条跨段咬合或哪类价格/证据判断。
- 是否区分“话术表面动作”和“结构功能完成”。
- 是否逐段指出二级任务缺口。
- 正式评分时是否使用不能升档规则。
- 是否把转化率目标当作业务上下文，而不是承诺结构改完就一定提升。

## Rewrite Quality

- 是否保留原稿里可用的教学承接、老师风格、真实互动和证明材料。
- 是否把每个优化句映射到结构段、二级任务、心理变化。
- 是否没有编造产品权益、售后、案例、数据、老师资质。
- 是否根据价格档位调整篇幅和行动目标。
- 免费入口转低客单时，是否优先补清“付多少钱、得什么、怎么返、怎么领、谁承接、何时截止”。
- 免费入口转高客单时，是否补足“免费体验复盘 -> 问题升级 -> 系统方案 -> 服务系统 -> 价格锚定 -> 风险逆转 -> 证据矩阵 -> 低阻力行动”的桥。
- 定金锁价是否讲清锁价期限、尾款、退转、权益和后续承接。
- 转阶进阶稿是否把“下一阶段更深入”改成“上一阶段成果 -> 下一层缺口 -> 正确标准 -> 产品交付 -> 证据/行动”的链路。
- 专业进阶课的报价是否选择合适策略：性价比策略或价值承接策略，而不是一律平摊成“每节很便宜”。
- 缺少下一阶段真实案例时，是否使用前一阶段反馈、机制演示、老师经验等过渡证据，并明确不能替代真实结果案例。
- 从案例复盘中改稿时，是否先抽象结构功能，再给话术骨架，最后才给行业化表达。

## Compliance Quality

- 健康、教育、金融、高客单咨询等敏感场景是否先看合规。
- 是否拦截绝对承诺、恐吓焦虑、虚假稀缺、无法证明案例。
- 是否把“承诺”改成“机制 + 边界 + 需要配合”。
- 是否避免用“全返/免费学”模糊初始付款和完成条件。
- 是否避免把一次免费体验、一个动作或一个反馈夸大成长期确定结果。

## Audience Fit

- 给课程顾问看：是否突出成交瓶颈和下一步。
- 给教研看：是否有结构证据和可复盘判断。
- 给讲师看：是否有保留/调整/新增话术/排练提醒。

## Minimum Passing Standard

一次更新后，至少跑通：

1. 一个 1 分失败案例。
2. 一个 5 分边界案例。
3. 一个 7 分成熟案例。
4. 一个高客单目标错配案例。
5. 一个0元/免费入口转几十元低客单案例。
6. 一个0元/免费入口转近3000元或几千元系统班案例。
7. 一个合规风险案例。
8. 一个信息不足但要求完整改稿的追问案例。
9. 一个训练营多波次销讲案例，包含全款波、定金波和助教报名承接。
10. 一个一阶转二阶/基础课转进阶课案例，包含主次人群、先标准后产品、模块价值和缺少下一阶段案例的处理。
11. 一个从复盘反馈提炼结构原则的案例，要求输出原理、原则、方法、检查项和落库位置，不能只沉淀行业案例。
