# 黄金评测样例

作者：范范之辈

这些样例用于检查 skill 输出是否稳定。所有内容均为虚构脱敏样例，不代表真实课程或学员。

## 评测方式

对每个样例运行提示后，检查输出是否满足“期望信号”。不要求逐字一致，但关键判断不能偏。

```text
必须包含：资料边界、八段识别、价格档位/转化目标、关键缺口、不能升档原因、下一步改稿动作。
禁止出现：虚构案例、虚构售后、绝对承诺、把小众问题当共性问题、把直接推课当方案承接。
```

## Case 1：1 分档，只有报价催促

提示：

```text
使用 $sales-conversion-eight-segment，给这段销讲打分：
今天课程到这里，想继续学习的同学赶紧报名。原价 3999，今天只要 999，最后 10 个名额，错过就没有了。助教把链接发一下，大家马上拍。
```

期望信号：

- 总分应接近 1 分。
- 不能给 3 分以上，因为没有完整购买判断链，只靠价格、优惠和名额催促。
- 应指出缺少问题唤醒、方案承接、价值塑造、降低顾虑、案例佐证。
- 不应因为有原价和优惠价就给高分。

## Case 2：3 分档，小众问题和直接推课

提示：

```text
使用 $sales-conversion-eight-segment，快速诊断：
刚才有个同学说自己一到晚上肩膀左侧酸，所以你们都需要买我们的肩颈进阶课。这个课内容很系统，今天名额有限，报名送资料。
```

期望信号：

- 总分应接近 3 分。
- 应指出“个别问题不等于问题唤醒”，相关力不足。
- 应指出“直接推课程不等于方案承接”。
- 不能给到 5 分以上。

## Case 3：5 分档，八段有但价值和顾虑弱

提示：

```text
使用 $sales-conversion-eight-segment，正式评分：
目标学员是 299 元训练营学员，刚学完基础动作。销讲内容：
刚才大家学会了动作，但回家最怕坚持不下来。要解决这个问题，需要有人带着练。我们的 7 天陪练营每天都有课程，还有讲义和社群，今天原价 699，优惠 299。前 50 名送动作图谱，报名后助教拉群。放心，大家都能学会。之前也有很多学员反馈不错。
```

期望信号：

- 总分应接近 5 分。
- 应承认八段基本有影子，但价值塑造、降低顾虑、案例佐证不足。
- 应指出“放心大家都能学会”缺机制，且有绝对化风险。
- 应建议补学习机制、作业反馈、相似案例和具体结果。

## Case 4：7 分档，结构清楚但证明和边界未满

提示：

```text
使用 $sales-conversion-eight-segment，按八段诊断并打分：
刚才大家完成了 3 分钟肩颈自测，很多人发现不是不会按，而是不知道自己属于哪种紧张类型。要想练得稳，先要学会判断，再选动作。7 天肩颈练习营会每天带你判断一个场景，配动作讲义、回放、作业提醒和社群答疑。因为助教每天要看作业，这期只收 80 人。正常价 699，今天训练营价 299。今天报名送动作图谱和 7 天提醒表，点链接提交后助教拉群。有同学担心零基础，课程会从自测开始，也有回放，但需要每天跟练。上一期有零基础学员跟练 7 天后，能清楚说出自己肩颈紧张的主要诱因，也能按表完成每日练习。
```

期望信号：

- 总分应接近 7 分。
- 应肯定八段顺序清楚，转化目标和价格档位匹配。
- 不能给 9 分的原因：案例结果仍偏轻，证据来源未说明，优惠/售后边界还可更清楚。
- 应给精修建议，而不是大改。

## Case 5：高客单目标错配

提示：

```text
使用 $sales-conversion-eight-segment，判断这段 19800 元线下认证班销讲是否适合现场全款成交：
刚才大家学了门店沟通的三个步骤，我们认证班原价 39800，今天 19800，名额只有 20 个，报名后送工具包，大家现在直接付全款。
```

期望信号：

- 应指出几万元/近两万元属于重决策或高决策。
- 应建议转化目标从现场全款改为预约诊断、资格评估、定金锁席或顾问承接。
- 应指出价值、顾虑、案例、合同/售后/时间投入不足。
- 不应只优化催单话术。

## Case 5B：0元表单到近3000元系统班

提示：

```text
使用 $sales-conversion-eight-segment，诊断这段0元表单用户听完免费营后转 2891 元系统班的销讲：
这几天大家已经免费体验了几个动作，也看到群里有同学说有帮助。可是一个动作解决不了长期复杂问题，真正要在家里做稳，需要系统学判断、顺序、禁忌和纠偏。我们的系统班包含30天线上课程、两天线下练习、讲义工具、回放、助教答疑和老师阶段点评，今天优惠价2891，名额有限。担心学不会的同学可以看回放，也有助教提醒作业；担心不适合的可以先找老师确认。报名后会发资料并拉入学习群。之前有零基础学员从免费营进入系统班，通过作业反馈逐步学会判断和练习，但具体效果因基础和练习情况不同。
```

期望信号：

- 应先建立“0元/免费入口 -> 几千元系统班”的高客单免费入口判断。
- 应指出免费体验获得感、问题升级、系统方案、服务系统、价格、顾虑、案例都有基础，因此不能判为低分。
- 不能直接给 9 分；原因是优惠边界、名额理由、退款/保障规则、证据授权和案例数量仍需更清楚。
- 应检查服务系统是否支撑 2891 元，而不是只看课程内容数量。
- 应把“找老师确认/助教提醒/回放”归入降低顾虑和行动承接，不应误判成案例佐证。

## Case 5C：0元表单到几十元低客单

提示：

```text
使用 $sales-conversion-eight-segment，诊断这段0元表单用户听完免费直播后转 58 元体验课的销讲：
刚才大家体验了一个在家能做的小方法，很多人发现原来自己也能找到问题点。今天周年福利，原价1000元的7节入门课只要58元，报名送讲义和练习工具，包邮。只要完成学习任务，58元会原路返还，相当于免费学。因为助教要逐个登记地址，先开放20个名额；没抢到的同学后面又加10个名额。想报名的点右下角立即抢购，填信息、提交订单、完成支付，报名后助教联系发地址和进课。有同学担心没时间，课程有一年回放；担心不会操作，助教现在再演示一次。
```

期望信号：

- 应识别这是“免费入口 -> 几十元低客单”，核心是低风险行动，不是高客单信任跃迁。
- 应重点检查58元付款性质、全返条件、返还方式/时间、赠品领取、助教步骤和名额边界。
- 应肯定低价课可以更快进入价格和优惠，但不能只靠“便宜、快抢、最后”。
- 不能因为价格低就忽略合规，应提醒健康结果表达不能绝对化。
- 如果返还时间或未完成任务规则缺失，应标为优惠政策和降低顾虑的残缺点。

## Case 6：合规风险拦截

提示：

```text
使用 $sales-conversion-eight-segment，检查并改写这段健康课销讲：
只要报名这个课，肩颈疼痛一定能好。今天不买以后会越来越严重，这是最后机会，之前所有学员都好了。
```

期望信号：

- 应明确标出健康领域合规风险。
- 应替换绝对承诺、恐吓焦虑、虚假稀缺和无法证明案例。
- 即使转化感强，也不能给 9 分。
- 改写应使用机制、边界、可证明反馈和真实机会边界。

## Case 7：信息不足时的分层追问

提示：

```text
使用 $sales-conversion-eight-segment，帮我完整改写一段销讲，目标是提升转化率。课程是健康类课程。
```

期望信号：

- 不应直接编写完整销讲话术。
- 应说明可以先暂判，但完整改稿缺关键前提。
- 应只追问 3-5 个最关键问题，不要一次抛出长表格。
- 问题应优先覆盖：卖什么和价格、转化目标、目标学员和刚听内容、已相信/未相信、最大阻力。
- 应提醒转化率目标需要历史转化率、样本量、流量来源和卡点，不能只靠话术结构承诺提升。

## Case 8：训练营多波次销讲

提示：

```text
使用 $sales-conversion-eight-segment，识别这段训练营福利课的销讲波次并诊断：
老师先教了一个实操动作，学员反馈有感觉。中段老师说正式营会系统带练，原价 3680，今天 1680，最后 20 个名额，助教教大家点链接报名、填姓名电话地址、提交订单。后面继续上课。快结束时老师说只剩几个名额，钱不够的可以先交 80 定金锁定 1680，之后补尾款；报名送讲义和工具，课程有回放。老师还说很多学员都好了，错过就对不起自己。
```

期望信号：

- 应先输出波次图，而不是只给八段表。
- 应区分教学主链、销讲桥接、全款成交波、助教操作波、定金锁价波、情绪收口。
- 应指出助教操作只解决行动路径，不等于完整优惠政策。
- 应指出定金锁价缺少锁价期限、尾款、退转和权益边界。
- 应标出健康结果绝对化和情绪压力表达的合规/信任风险。
- 应把“很多学员都好了”判为案例佐证不足，要求相似性、结果、路径和证据边界。

## Case 9：一阶转二阶进阶营

提示：

```text
使用 $sales-conversion-eight-segment，诊断这份一阶转二阶进阶营销讲设计，并说明为什么不能直接给 9 分：
目标学员是基础营学员，前一阶段已经学会基础判断，能发现一些异常，但还不能在真实应用里稳定判断具体问题、清楚表达并形成后续方案。下一阶段进阶营 1999 元，目标是全款转阶报名。原稿先说“基础营给判断，进阶营给答案”，再讲三个目标人群：门店经营者、刚入行从业者、家庭自用者；随后介绍进阶营 4 个模块 15 节课，包含地图建立、具体问题对应、案例拆解和接诊闭环。报价用线下跟学成本做锚定：原价 4999，转阶价 1999，赠送工具包，50 个名额。当前没有进阶营真实案例，只有基础营反馈、老师经验和课程机制说明。
```

期望信号：

- 应先建立“前一阶段成果 -> 下一阶段缺口 -> 进阶产品承接”的转阶卡，而不是直接进入普通八段表。
- 应肯定“基础营给判断，进阶营给答案”是可用升级主张，但要检查中间因果链是否完整。
- 应指出问题唤醒要递进收口：泛共识问题、专业学习问题、真实应用/结果问题。
- 应指出方案承接必须先提出用户认可的标准，例如“什么样的方法才能从异常走到具体判断”，再引出进阶营。
- 应检查多类人群是否稀释主线：主目标人群应完整承接，次目标人群只在高相关模块轻量承接。
- 应检查 4 个模块 15 节课是否下沉到“解决什么问题、怎么交付、拿到什么结果感”，不能只当课程目录。
- 应指出专业进阶课不必一味讲便宜；可以用价值承接策略，让 1999 显得“有门槛但值得”。
- 应把基础营反馈、老师经验、机制演示判为过渡证据，不得当成进阶营学员成功案例。
- 不能给 9 分的原因通常包括：缺少下一阶段真实案例、行动路径/服务规则/回放或售后边界不完整、价格锚定证据需要确认。

## Case 10：从复盘反馈提炼结构原则

提示：

```text
使用 $sales-conversion-eight-segment，我提供一段销讲复盘讨论，请提炼哪些内容适合补充到 skill。重点不是具体行业案例，而是销讲转化结构的原理、原则和方法。
复盘讨论要点：
1. 提出问题不是让用户质疑，而是让用户先认同一个共性问题。
2. 问题要从大多数人都相关的泛问题，逐步收口到本场要解决的关键问题。
3. 解决方案不是直接说“我们的课程就是答案”，而是先提出用户认可的方案标准，再证明产品符合标准。
4. 价值塑造不是罗列课程目录，而是每个模块都要说清解决什么问题、通过什么机制、让学员拿到什么结果感。
5. 多类人群不能平均展开，主目标人群决定主线，次目标人群轻量承接。
6. 价格不一定要讲得很便宜，专业产品可以讲得有门槛但值得。
7. 缺少直接案例时，可以用前置反馈、机制演示、老师经验做过渡证据，但不能冒充结果案例。
```

期望信号：

- 应先输出原则级结论，而不是复述具体场景或行业案例。
- 应按“原理 -> 原则 -> 方法 -> 检查项 -> 话术骨架/脱敏样例 -> 放入 skill 的位置”组织。
- 应识别至少这些结构原则：共识优先、递进收口、先标准后产品、价值下沉、主次人群、价格策略选择、证据边界。
- 应说明每条原则增强哪个八段模块或跨段咬合。
- 应避免把具体行业词、具体病症、具体产品名写入核心规则。
- 应建议把通用原则放入 `conversion-structure-principles.md` 或 `framework.md`，把场景应用放入对应 reference，把案例放入 `evals`。
