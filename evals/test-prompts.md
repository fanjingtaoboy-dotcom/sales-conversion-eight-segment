# 测试提示

作者：范范之辈

这些提示用于测试 skill 是否能稳定触发并输出可用结果。示例均为虚构内容，不包含真实课程逐字稿。

## 快速诊断

```text
使用 $sales-conversion-eight-segment，帮我快速诊断这段销讲：
刚才大家已经学会了一个肩颈放松动作，接下来我们的进阶班今天只要 1280，原价 3980，最后 20 个名额，赠送很多资料，大家赶紧拍，学不会也不用担心，很多学员都说有效。
```

## 正式评分

```text
使用 $sales-conversion-eight-segment，按 1/3/5/7/9 给这段销讲打分，并说明为什么不能更高：
目标学员是训练营里的中老年健康学习者，刚学完一个基础自测动作。产品是 299 元 7 天练习营，目标是全款购买。原稿如下：
刚才的方法大家都觉得有用，但真正回家自己做，最难的是不知道自己适不适合、顺序怎么安排。要把效果做稳，不能只记一个动作，而要有一套从判断到练习的流程。我们这期 7 天练习营会带大家每天练一个场景，配讲义和作业提醒。今天训练营价 299，赠送动作图谱和 7 天社群提醒，现在点链接报名。
```

## 高客单目标校验

```text
使用 $sales-conversion-eight-segment，判断这个 19800 元线下班的销讲目标应该是全款成交，还是预约诊断/定金锁席，并给八段结构建议。
```

## 0元表单到近3000元系统班

```text
使用 $sales-conversion-eight-segment，诊断这段0元表单用户听完免费营后转 2891 元系统班的销讲。请先判断免费体验、信任加热、offer服务系统、风险逆转和案例证据是否足够，再按八段给优化建议：
这几天大家已经跟着做了基础体验，也看到一些同学有反馈。单靠一个动作只能临时有感觉，真正想在家里长期练稳，需要学会判断、顺序和纠偏。系统班有30天线上课、作业提醒、助教答疑、长期回放和工具资料，今天优惠价2891。现在只剩少量名额，报名后老师会把资料发给大家，也有学习保障。有同学担心自己年龄大、学不会，可以看回放慢慢学，之前也有不少同学学得不错。想报名的点链接。
```

预期：应识别这是低承诺入口到高客单购买，不应只按普通训练营福利课判断；应检查入口热度、信任缺口、服务系统、保障规则、证据矩阵和行动路径。

## 信息不足追问

```text
使用 $sales-conversion-eight-segment，帮我完整改写一段健康课程销讲，目标是提升转化率。
```

预期：不要直接编完整销讲话术；先说明完整改稿缺少关键前提，并只追问 3-5 个最影响结果的问题。

## 教学到销讲衔接

```text
使用 $sales-conversion-eight-segment，帮我判断这节交付课从总结回顾过渡到报名转化是否自然，并给一版衔接话术。
```

## 训练营多波次识别

```text
使用 $sales-conversion-eight-segment，下面是一节训练营福利课转写片段，请先识别销讲波次，再判断哪些内容属于主讲说服、助教报名承接、报名播报、作业收尾：
前半段老师教了一个实操动作，中间说后续正式营会系统带练。随后出现第一轮营销：原价 3680，今天 1680，最后 20 个名额，助教教大家点链接报名。后半段继续讲课。快结束时老师说有人钱不够，可以先交 80 定金锁定 1680，之后补尾款，助教再教一次怎么提交订单。
```

## 合规检查

```text
使用 $sales-conversion-eight-segment，检查下面这段健康课程销售话术有没有合规风险，并改成更稳妥的表达：
只要报名这个课，肩颈问题一定能解决，今天不买以后肯定更严重，这是最后一次机会。
```
