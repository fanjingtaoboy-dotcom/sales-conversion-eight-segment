## 诊断深度

诊断销讲话术时，不能只判断一级模块是否存在，也不能只写“推荐优化”。每一段必须至少深入到二级任务层面，逐项判断“原稿完成了哪些二级任务、缺了哪些二级任务、这些缺失如何影响学员购买心理推进”。

正式评分、深度诊断和改稿重构时，不能停在二级任务，还必须继续展开三级验收点。

## 三级验收点总表

| 一级模块 | 二级任务 | 三级验收点 |
|---|---|---|
| 问题唤醒 | 承接刚才教学 | 是否回扣刚才的教学、实操、自测、反馈或评论区问题 |
| 问题唤醒 | 锁定大多数目标学员 | 问题是否覆盖目标学员中的多数人，而不是个别小众场景 |
| 问题唤醒 | 呈现共性问题 | 是否把零散问题归纳成共同问题，例如诊断不准、判断不清、调理无序 |
| 问题唤醒 | 放大相关性 | 是否让学员产生“这也在说我”的判断 |
| 问题唤醒 | 留下方案入口 | 是否自然引出需要一个正确方案，而不是直接跳到课程产品 |
| 方案承接 | 避免直接推产品 | 是否先说正确道理/正确方案，而不是一上来就说买课 |
| 方案承接 | 提出正确道理 | 是否提出学员容易接受的原则，例如要提升诊断能力、要先判断再调理 |
| 方案承接 | 解释正确方案 | 是否说明这个正确方向为什么能解决前面的问题 |
| 方案承接 | 让学员先认同方向 | 是否先让学员认可方案逻辑，再引出产品 |
| 方案承接 | 引出课程承接 | 是否把课程作为正确方案的落地工具，而不是强行推销 |
| 价值塑造 | 对应具体问题 | 每个价值点是否对应学员的某个具体问题 |
| 价值塑造 | 拆解核心价值点 | 是否把课程价值拆成清楚的能力、服务、工具、结果 |
| 价值塑造 | 说明解决路径 | 是否讲清课程如何帮助学员从问题走向结果 |
| 价值塑造 | 解释价值点作用 | 是否说明每个价值点为什么对学员有用 |
| 价值塑造 | 强化结果感 | 学员是否能想象学完后能解决什么、提升什么 |
| 制造稀缺 | 给出机会边界 | 是否说明名额、时间、班期、资格、服务容量或赠品边界 |
| 制造稀缺 | 解释稀缺理由 | 稀缺是否有可信原因，而不是单纯倒计时 |
| 制造稀缺 | 制造获得不易 | 是否让学员觉得不是随时随地都能买到 |
| 制造稀缺 | 调动情绪 | 是否产生机会感、珍惜感、错过感，而不是恐吓 |
| 制造稀缺 | 避免虚假稀缺 | 是否避免反复追加名额、无限延长优惠等破坏信任的动作 |
| 报出价格 | 价格锚定 | 是否先建立价值/市场/服务/成本参照，而不是直接报最终价 |
| 报出价格 | 报原始价格 | 是否清楚说明原始价格或正常价格 |
| 报出价格 | 证明原价划算 | 是否让学员觉得按原价购买也有价值 |
| 报出价格 | 报优惠价格 | 是否清楚报出本场优惠价格 |
| 报出价格 | 完成价格接受 | 学员是否能理解优惠价为什么更值得 |
| 优惠政策 | 说明额外福利 | 是否讲清课程之外还有哪些额外福利 |
| 优惠政策 | 说明赠品权益 | 是否说明赠品是什么、解决什么问题、如何领取 |
| 优惠政策 | 说明领取条件 | 是否讲清优惠/赠品/权益的时间、名额、报名条件 |
| 优惠政策 | 说明报名步骤 | 是否告诉学员点击哪里、填写什么、如何提交 |
| 优惠政策 | 给出行动指令 | 是否有清晰、低阻力、可执行的报名指令 |
| 降低顾虑 | 识别购买顾虑 | 是否识别学不会、听不懂、有没有用、没时间、售后等顾虑 |
| 降低顾虑 | 回应学习难度 | 是否说明零基础、年龄大、记不住等情况如何学习 |
| 降低顾虑 | 回应效果担心 | 是否说明课程如何帮助产生结果，并说明边界 |
| 降低顾虑 | 说明售后保障 | 是否说明回放、答疑、作业、助教、退款、服务保障等 |
| 降低顾虑 | 给出承诺与边界 | 是否既有承诺，又避免绝对化和违规承诺 |
| 案例佐证 | 选择相似案例 | 案例人物是否和目标学员在问题、基础、顾虑、目标上相似 |
| 案例佐证 | 展示成功结果 | 是否展示具体结果，而不是泛泛说效果好 |
| 案例佐证 | 讲清成功路径 | 是否说明对方为什么成功，课程/服务如何发挥作用 |
| 案例佐证 | 制造从众效应 | 是否让学员看到“很多人都在学/都成功/都行动” |
| 案例佐证 | 以情动人 | 是否通过故事、变化、情绪感染增强行动意愿 |
| 案例佐证 | 回到行动 | 案例后是否回扣“你也可以行动”，而不是故事讲完就断 |

## 二级任务缺失的典型误判

| 表面动作 | 容易误判为 | 实际问题 |
|---|---|---|
| 讲一个个别病症 | 问题唤醒 | 问题太小众，无法唤醒大多数目标学员 |
| 直接说你需要某课程 | 方案承接 | 太早暴露产品，容易引发抗拒 |
| 讲课程有很多模块 | 价值塑造 | 没有把模块对应到学员具体问题 |
| 说名额有限 | 制造稀缺 | 没有解释为什么有限，稀缺不可信 |
| 直接报优惠价 | 报出价格 | 缺少价格锚定和原始价格，学员只判断贵不贵 |
| 讲很多赠品 | 优惠政策 | 没有说清赠品作用和领取条件 |
| 说放心能学会 | 降低顾虑 | 没有具体机制和保障 |
| 讲成功故事 | 案例佐证 | 没有相似性、结果、路径和从众效应 |

## 主要问题深拆标准

“主要问题”不能写成泛泛评价，例如“偏弱”“不够聚焦”“需要加强”。必须写出结构误判和二级任务缺口。

主要问题深拆必须包含六层：

1. 表面动作：原稿具体做了什么。
2. 结构误判：这个动作容易被误判为完成了什么，但实际上没有完成。
3. 本质缺口：缺失的是哪个二级任务。
4. 三级缺口：具体缺了哪个验收点。
5. 心理推进失败：学员没有完成哪一步购买心理变化。
6. 后续影响：如果不改，后面的哪一段会变弱。

判断句要具体、可启发：

```text
这只是“讲了一个问题”，不是“问题唤醒”。问题只击中了少数人，没有建立大多数目标学员的相关感。
```

```text
这只是“推出课程”，不是“方案承接”。学员还没先认可正确方案，就被要求接受课程产品，容易产生抗拒。
```

```text
这只是“讲案例”，不是“案例佐证”。案例没有相似性、结果和成功路径，不能形成从众和行动信心。
```

## 逐段诊断输出要求

### 二级任务核查表

每段诊断必须包含二级任务核查表。最低格式：

| 二级任务 | 原稿证据 | 判定 | 缺口 | 对心理推进的影响 |
|---|---|---|---|---|
| 本段应完成的任务 | 原稿对应句子或行为 | 达标 / 部分达标 / 缺失 | 没有完成什么 | 学员卡在哪一步 |

### 三级验收核查表

正式评分、逐字稿深度诊断和改稿重构时，每段还要补充三级验收核查表。最低格式：

| 二级任务 | 三级验收点 | 原稿证据 | 判定 | 扣分点 | 改稿动作 |
|---|---|---|---|---|---|
| 本段关键任务 | 怎样才算完成 | 原稿句子或行为 | 达标 / 部分达标 / 缺失 | 缺哪一项验收 | 补什么话术或结构 |

## 严格判定语言

诊断时要避免为了情绪价值而降低判定标准。

| 情况 | 不要写 | 应该写 |
|---|---|---|
| 问题只击中少数人 | 问题唤醒偏窄 | 相关力不足，问题唤醒不合格 |
| 直接推出课程 | 方案承接略急 | 缺少低抗拒方案承接 |
| 只介绍课程内容 | 价值塑造偏弱 | 没有把价值点对应到具体问题 |
| 只有倒计时 | 稀缺感强 | 稀缺理由不足，存在虚假稀缺风险 |
| 只报优惠价 | 价格便宜 | 缺少价格锚定和原始价格 |
| 只说赠品多 | 福利丰富 | 优惠政策没有说明赠品作用和领取条件 |
| 只说放心 | 顾虑处理简略 | 降低顾虑不合格，缺少保障机制 |
| 只有截图 | 案例不少 | 案例佐证不完整，缺少相似性、路径和结果 |

## 八段分段检查问题

### 1. 问题唤醒

合格判断：

1. 是否承接了刚才教学、自测、实操、评论区反馈或案例共鸣？
2. 这个问题是否和大多数目标学员相关？
3. 是否从个别现象上升到共性问题？
4. 是否让不同类型学员都能代入？
5. 是否自然留下方案入口，而不是直接推产品？

常见不合格：把个别病症、严重后果、课程回顾或直接推课当成问题唤醒。

### 2. 方案承接

合格判断：

1. 是否先讲了学员容易认可的正确道理？
2. 是否避免一开始就说课程产品？
3. 是否解释正确方案为什么能解决前面的问题？
4. 是否让学员先认同方向，再接受课程？
5. 课程是否作为方案落地工具出现，而不是突然硬推？

常见不合格：把推出课程、课程卖点、“这个课很重要”或太专业的方案当成方案承接。

### 3. 价值塑造

合格判断：

1. 价值点是否对应学员具体问题？
2. 是否讲清课程如何解决这些问题？
3. 是否避免只堆课程内容和老师配置？
4. 学员听完是否知道“这对我有什么用”？
5. 是否和方案承接中的正确方向保持一致？

常见不合格：把课程介绍、功能多、老师厉害或结果承诺当成价值塑造。

### 4. 制造稀缺

合格判断：

1. 稀缺是否出现在价值塑造之后？
2. 稀缺理由是否真实可信？
3. 是否让学员觉得机会不容易获得？
4. 是否避免恐吓、羞辱、虚假紧迫？
5. 是否为报出价格和优惠政策做铺垫？

常见不合格：把倒计时、剩余名额、反复催促或单纯优惠截止当成稀缺全部。

### 5. 报出价格

合格判断：

1. 是否先做价格锚定，而不是直接报最终价？
2. 是否清楚报出原始价格？
3. 是否说明原始价格为什么合理或划算？
4. 是否再报出优惠价格？
5. 学员是否能理解优惠价为什么更值得？

常见不合格：只有优惠价、虚高原价、用赠品价值相加代替价格依据、把便宜当全部说服力。

### 6. 优惠政策

合格判断：

1. 优惠政策是否和报出价格区分开？
2. 额外福利和赠品是否逐项讲清？
3. 每个赠品是否说明了作用？
4. 领取条件是否清楚？
5. 是否顺带说明报名步骤和行动指令？

常见不合格：只说赠品多、重复报价格、报名步骤太晚、赠品盖过主价值。

### 7. 降低顾虑

合格判断：

1. 是否识别了本场最关键的购买顾虑？
2. 是否正面回答学不学得会、听不听得懂、有没有用？
3. 是否有具体学习支持和售后保障？
4. 是否给出了承诺和边界？
5. 是否避免绝对效果承诺？
6. 顾虑降低后是否回到报名动作？

常见不合格：把退款、“放心”、案例或绝对承诺当成完整顾虑处理。

### 8. 案例佐证

合格判断：

1. 案例是否和目标学员相似？
2. 是否展示了具体成功结果？
3. 是否讲清成功路径，而不是只讲结果？
4. 是否形成从众效应？
5. 是否以情动人，而不是只堆截图？
6. 案例后是否回到行动？
7. 是否合规、真实、可证明？

常见不合格：把截图、极端成功案例、结果承诺或讲完不收口当成案例佐证。
