# 训练营多波次销讲

## Core Rule

训练营、福利课和多日直播课里的销讲通常不是一段连续话术，而是多波次推进。不要只找“销讲开始到结束”的单一边界；要先画出全场或全营的销售波次，再判断八段结构是否在整体链路中被完成。

所有真实逐字稿都只作为私密素材。沉淀到 skill 时只保留脱敏模式，不保留真实姓名、疾病细节、订单信息、学员反馈原文或完整话术。

## Three-Layer Boundary

| 层级 | 定义 | 处理方式 |
|---|---|---|
| 教学主链 | 正在教知识、动作、原理、案例或作业 | 不按销讲八段评分，但可判断是否产生 S0 教学获得 |
| 销讲桥接 | 用刚才教学引出“后续还需要系统学习/陪练/工具/服务” | 归入问题唤醒或方案承接，检查是否自然、低抗拒 |
| 明确销讲 | 出现课程产品、价格、优惠、名额、赠品、报名、定金、助教操作、支付路径 | 进入八段诊断和行动路径检查 |

## Common Wave Types

| 波次类型 | 常见信号 | 主要归属 | 诊断重点 |
|---|---|---|---|
| 价值预埋波 | 后面课程会教、正式班会带、先给大家看一下 | 问题唤醒 / 方案承接 | 是否承接刚才教学，而不是突然硬广 |
| 低价占位波 | 几十元抢名额、学费全返、赠书赠工具、包邮 | 报出价格 / 优惠政策 / 降低行动阻力 | 是否讲清付款性质、返还条件、赠品领取和进课路径 |
| 全款成交波 | 原价、优惠价、今天报名、剩余名额、立即购买 | 报出价格 / 优惠政策 / 制造稀缺 | 是否有价格锚定、真实稀缺、清晰行动路径 |
| 福利恢复波 | 错过优惠、老师特权、再加名额、插班 | 制造稀缺 / 优惠政策 | 是否解释恢复理由，避免虚假稀缺或反复追加破坏信任 |
| 助教操作波 | 点链接、填信息、勾选、提交订单、支付、联系班主任 | 优惠政策 / 降低行动阻力 | 是否把报名步骤讲到能执行，是否提醒失败点和后续承接 |
| 定金锁价波 | 先交定金、锁定优惠价、后补尾款、钱不够也能占名额 | 报出价格 / 优惠政策 / 降低顾虑 | 是否说明锁价期限、尾款规则、退转规则、权益是否保留 |
| 报名播报波 | 又有人报名、只剩几个、后台显示、名额减少 | 制造稀缺 / 案例佐证 | 是否增强从众和机会感，不能替代真实案例 |
| 顾虑问答波 | 学不会、没时间、记不住、钱不够、年龄大、是否适合 | 降低顾虑 | 是否用机制回答，而不是只说“放心” |
| 作业收尾波 | 今日作业、继续发群里、助教点评、课程结束 | 教学闭环 / 关系维护 | 通常不算销讲主线，除非回到明确报名动作 |

## Wave Map Procedure

For a training camp transcript or a group of transcripts:

1. Locate explicit labels and signals: 第一轮营销, 第二轮营销, 推出产品, 打消顾虑, 报名, 链接, 原价, 优惠, 名额, 定金, 助教, 下单, 作业.
2. Group nearby sales signals into waves. A wave can be short, repeated, or interrupted by teaching.
3. For each wave, record position, speaker role, trigger, offer elements, price/action target, and likely eight-segment functions.
4. Mark whether the wave is 主讲说服, 助教操作, 场控提醒, 报名播报, or 情感收束.
5. Decide whether to diagnose the whole sales arc, a single wave, or both. If the user asks for course-level improvement, diagnose both.
6. Check consistency across waves: price, discount, quota, bonus, deadline, service promise, refund/guarantee, and action path must not contradict.

## Training Camp Arc Checks

| 检查项 | 好信号 | 风险信号 |
|---|---|---|
| 课程获得感 | 每轮销讲前都有教学收获或互动反馈承接 | 教学还没交付就频繁催单 |
| 价格路径 | 原价、优惠价、定金、尾款关系清楚 | 全款、定金、优惠反复切换但规则不清 |
| 稀缺可信 | 名额来自助教服务、班级容量、赠品库存、开班排期 | 反复“最后几个”又不断追加 |
| 助教承接 | 主讲制造购买理由，助教降低操作阻力 | 助教只催支付，没有补清楚步骤和保障 |
| 赠品权益 | 赠品解决记不住、不会练、缺资料、缺工具等具体问题 | 赠品堆叠但不知道有什么用 |
| 顾虑处理 | 钱不够、没时间、学不会、年龄大等都有机制回应 | 用“肯定能学会/一定有效”代替机制 |
| 案例证明 | 有相似学员的起点、过程、结果和证据边界 | 只用报名播报、泛泛好评或极端结果代替案例 |
| 合规信任 | 健康/收益表达有边界，避免恐吓和绝对承诺 | 用疾病恐惧、保证效果、夸大收益强推 |

## Rewrite Guidance

When improving a training camp sales arc:

1. Keep high-value teaching and real interaction; compress repeated pressure language.
2. Give each wave one job. Do not let every wave repeat price, quota, bonus, and fear at the same strength.
3. Use the first wave to establish value and full-payment action.
4. Use later waves to handle objections, clarify action path, or offer a lower-commitment target such as deposit or consultation.
5. Make assistant handoffs scripted: repeat offer, explain steps, mention common submission errors, confirm service entry after payment, then hand back to teaching or Q&A.
6. Replace risky certainty with mechanism plus boundary: learning support, replay, practice, feedback, and user effort.
