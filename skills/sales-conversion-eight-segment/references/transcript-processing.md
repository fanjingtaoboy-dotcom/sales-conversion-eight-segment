# 长逐字稿处理

## Core Rule

当用户给的是完整课程逐字稿、直播转写、ASR 文本或教学+销售混合稿，先切清楚“哪里还是教学，哪里开始销讲”，再做八段诊断。不要直接把全稿硬套八段。

## Processing Steps

1. 清洗噪音：去掉重复口头禅、无意义确认、明显 ASR 错字，但保留能影响结构判断的互动、助教提示、报价、案例、顾虑问答。
2. 标出教学到销讲边界：寻找总结回顾、结尾升华、课程介绍、报名链接、价格、优惠、名额、案例、助教承接等信号。
3. 建立素材地图：把销售相关内容按时间/段落位置列出来。训练营或福利课要额外建立“波次图”，因为销售可能多次出现又回到教学。
4. 初步归类八段：判断每段是否存在，避免按标题而不按功能判断。
5. 标记非主线内容：福利、答疑、倒计时、报名播报、互动、助教发链接，按功能归入对应段。
6. 再进入诊断：先判断关键断点，再展开二级/三级核查。

## Sales Boundary Signals

| 信号 | 可能含义 | 处理方式 |
|---|---|---|
| “刚才大家已经学到...” | 教学总结或销讲承接起点 | 看是否继续总结，还是转入共性问题 |
| “真正难的是...” | 问题唤醒 | 判断是否覆盖大多数目标学员 |
| “所以需要一套...” | 方案承接 | 判断是否先讲正确方向 |
| “我们的课程会...” | 价值塑造或硬推产品 | 判断是否对应具体问题 |
| “这次名额/班期/优惠...” | 制造稀缺 | 判断稀缺理由是否真实 |
| “原价/今天价...” | 报出价格 | 判断是否有价格锚定 |
| “赠送/福利/权益...” | 优惠政策 | 判断作用和领取条件是否清楚 |
| “担心学不会...” | 降低顾虑 | 判断是否有机制和边界 |
| “上一期学员...” | 案例佐证 | 判断相似性、结果、路径、从众 |
| “第一轮营销/第二轮营销/推出产品” | 人工标注的销售波次 | 只作为线索，仍按实际功能归类 |
| “助教教大家怎么报名” | 行动路径承接 | 归入优惠政策或降低行动阻力，检查步骤是否可执行 |
| “先交定金/锁定价格” | 转化目标切换 | 检查定金、锁价、尾款、退转和权益规则 |

## Multi-Wave Transcript Rule

如果一节课里多次出现报名、优惠、名额、助教承接、定金或下单操作，不要强行合并成一个连续销讲段。先判断：

1. 哪些是教学主链。
2. 哪些是销讲桥接。
3. 哪些是明确销讲波次。
4. 哪些只是助教操作、报名播报、作业收束或关系维护。

对每个波次记录“触发点、角色分工、目标动作、八段归属、主要风险”。如果用户给的是同一训练营多份稿，读取 `training-camp-patterns.md` 并做跨样本波次总结。

## Long Transcript Warnings

- 不要因为话术很长就判为完整。长度不等于二级任务完成。
- 不要因为互动多就判为有效。互动必须服务某个心理推进段。
- 不要因为案例多就判为案例佐证强。案例必须相似、有结果、有路径、有行动收口。
- 不要因为报价出现多次就判为价格模块合格。价格必须有锚定、原价、优惠价和接受理由。
- 不要把教学案例误判为销讲案例。教学案例用于理解知识，销讲案例用于增强购买信任和行动。
- 不要把“助教教报名”误判为完整优惠政策。它只解决行动路径，仍要检查权益、领取条件、保障和后续承接。
- 不要把“定金锁价”误判为完整低价成交。定金必须有锁价期限、尾款规则、权益保留和退转边界。
