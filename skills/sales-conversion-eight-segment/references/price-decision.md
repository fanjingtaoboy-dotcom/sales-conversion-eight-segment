# 价格决策难度与结构权重

## Core Rule

销讲八段的顺序稳定，但每段权重要根据购买决策难度调整。价格是最直观的分层标准，几十元、几百元、几千元、几万元分别对应不同心理阻力。

| 价格档位 | 决策难度 | 学员主要心理 | 结构重点 |
|---|---|---|---|
| 几十元 | 低决策，偏冲动购买 | 不贵，先占一个也可以 | 快速唤醒、快速价值、强稀缺、强优惠、短顾虑 |
| 几百元 | 轻中决策，需要基本确认 | 有点心动，但要确认值不值 | 清楚价值、明确优惠、短案例、行动便利 |
| 几千元 | 高决策，需要信任和顾虑处理 | 值不值、敢不敢、能不能学会 | 价值塑造、价格锚定、降低顾虑、案例佐证 |
| 几万元 | 重决策，通常需要多触点成交 | 需要深度评估、家人/团队参与、强信任 | 方案诊断、长期价值、资格稀缺、咨询/预约/定金承接 |

## 几十元低价产品

几十元产品通常是资料包、低价体验课、小专题课、入门权益。学员决策难度低，更容易受即时利益、优惠感和紧迫感推动。

推荐权重：

```text
问题唤醒：短，但必须广泛相关
方案承接：短
价值塑造：短
制造稀缺：重
报出价格：快
优惠政策：重
降低顾虑：轻
案例佐证：短
```

诊断重点：

1. 可以更快进入价格和优惠，但不能省略相关性。
2. 稀缺、优惠、赠品、立即领取可以更靠前更强。
3. 案例佐证可用短反馈、购买人数、领取反馈形成从众。
4. 行动指令要极简，减少咨询和复杂解释。

### 0元/免费入口转几十元

0元表单、免费直播、结缘营或福利课用户转几十元产品时，购买动作通常是“低价占位”或“低风险继续学”。这类销讲不需要高客单式长证明，但必须把低价权益和规则讲得非常清楚。

诊断重点：

1. 先承接刚刚的免费体验，让学员知道不是凭空卖课。
2. 低价可以更早出现，但要说明它买到什么：课程、回放、书籍、工具、包邮、社群或答疑。
3. 如果使用“学费全返/相当于免费学”，必须说明返还条件、返还方式、返还时间和未完成任务怎么办。
4. 助教操作要细，低价产品最怕学员心动但不会点、不会填、不会付款、不会领赠品。
5. 名额、截止和追加名额要有边界，反复从限量改成不限量会削弱信任。
6. 低价不代表可以忽略合规，健康和效果表达仍要避免绝对承诺。

## 几百元轻中决策产品

几百元产品通常是专题训练营、短期陪跑、轻量系统课或小班体验。学员会考虑，但决策成本不重。

诊断重点：

1. 问题唤醒要覆盖多数目标学员。
2. 方案承接要先讲正确方向，再讲课程。
3. 价值塑造要说明课程解决哪些具体问题。
4. 优惠政策要讲清赠品、服务和截止时间。
5. 降低顾虑不必过长，但要处理最主要的 1-2 个担心。

## 几千元高决策课程

几千元课程通常是系统班、进阶班、长期训练营、健康调理学习项目。学员心理不是“不知道要不要点”，而是“不确定值不值、敢不敢、适不适合我”。

诊断重点：

1. 问题唤醒不能太窄，要用共性问题覆盖大多数目标学员。
2. 方案承接要更柔和，先让学员认可正确道理，再引出课程产品。
3. 价值塑造要充分，把课程价值点逐一对应到学员具体问题。
4. 制造稀缺要有服务容量、班期、老师精力、优惠政策等真实理由。
5. 报出价格必须先锚定价值，再报原始价格和优惠价格。
6. 降低顾虑和案例佐证必须扎实，否则学员会心动但不敢买。

### 0元/免费入口转几千元

0元表单、免费营、结缘营、福利课用户转近 3000 元或几千元系统班时，要把它判为“低承诺体验到高信任购买”的跨越。学员不是完全陌生，但也不能按老学员或强信任用户处理。

诊断重点：

1. 先看免费体验是否产生了可被复盘的获得感：听课、作业、实操、互动、老师反馈。
2. 不能只说“免费内容不够”，要解释为什么系统学习、反馈纠偏、长期服务才是正确方案。
3. 价格锚定要围绕系统交付、服务容量、长期使用价值和当前低效尝试成本，不要只靠恐惧和原价虚高。
4. 报价前后必须有风险逆转：回放、答疑、售后、退款、适配边界、服务规则。
5. 案例佐证要从一个成功故事升级为证据矩阵：免费营反馈、相似学员、学习过程、服务承接、多问题覆盖。
6. 如果学员热度不足，全款购买未必是唯一目标，可以设计为加微信咨询、预约诊断、定金锁席或顾问承接。

## 几万元重决策课程

几万元课程通常是深度训练营、线下班、认证班、门店/职业项目、高端健康服务或长期陪跑。它的购买通常不适合只靠一轮直播强行完成全款成交，而应该把一轮销转目标设计为预约咨询、资格评估、定金锁席、顾问承接或私域深聊。

诊断重点：

1. 方案承接要更像诊断和战略建议，而不是直接卖课。
2. 价值塑造要强调长期收益、机会成本、服务体系和适配人群。
3. 制造稀缺应围绕资格、名额、服务能力、线下席位、导师时间。
4. 降低顾虑要处理家人/团队决策、时间投入、合同/售后等重顾虑。
5. 案例佐证要用高相似、高可信、过程完整的深案例。

## 转化目标匹配

| 目标 | 适合场景 | 检查重点 |
|---|---|---|
| 全款购买 | 低价或信任基础强、权益清晰、行动路径简单 | 八段可较短，但价格接受和行动指令必须清楚 |
| 定金锁单 | 中高价、有名额或班期边界、需要后续补决策 | 定金权益、退转规则、后续步骤必须清楚 |
| 加微信咨询 | 需要顾问承接、学员问题差异大、客单较高 | 销讲目标是“愿意进一步聊”，不是强行全款 |
| 预约诊断 | 高价服务、需要资格评估、适配度重要 | 方案承接和顾虑处理要像专业评估 |
| 进入社群 | 低承诺转化、培育后续成交 | 行动成本低，但必须说明进入后获得什么 |

## Weighting Warnings

- 几十元产品不能讲成几万元咨询式长销讲，否则行动阻力变大。
- 免费入口转几十元产品不能只说“免费/全返/快抢”，必须讲清付款、返还、赠品和行动规则。
- 几千元产品不能只用几十元的“抢优惠”逻辑，否则信任和顾虑处理不足。
- 免费入口转几千元产品不能只用“你已经体验到了，赶紧报名”的逻辑，否则会高估信任基础。
- 几万元产品不能只追求现场全款；目标错了，即使八段存在也很难高分。
- 价格锚定不能靠虚高原价和赠品价值堆叠，必须和主课程价值、服务成本、学习周期、市场参照或长期使用价值有关。

## 定金锁价与全款切换

训练营直播里常见从全款购买切到定金锁价。诊断时先判断这是“转化目标调整”，不是单纯多一个优惠。

合格的定金锁价必须讲清：

1. 定金金额和能锁定什么：价格、名额、赠品、班期或咨询资格。
2. 锁价期限：保留多久，过期怎么处理。
3. 尾款规则：什么时候补、补多少、在哪里补。
4. 退转规则：是否可退、可转、可抵扣，条件是什么。
5. 权益边界：交定金是否等同报名，是否能进群、拿赠品、看回放、享服务。
6. 后续承接：助教、班主任或顾问如何联系。

如果只说“交一点钱就锁定优惠”，但没有期限、尾款、退转和权益边界，判定为“定金政策不完整”。这会降低优惠政策、降低顾虑和行动路径的评分。
