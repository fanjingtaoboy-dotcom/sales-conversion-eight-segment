# 合规与信任边界

## Core Rule

健康、教育、金融、认证、就业、创业、高客单咨询等高敏感品类必须先合规，后转化。高转化话术如果存在明显合规风险，不能给 9 分。

## High-Risk Claims

Avoid or flag:

- 绝对结果承诺：一定学会、一定有效、包治、稳赚、保证拿证、保证就业。
- 恐吓焦虑：不买就严重恶化、不报名就错过人生机会。
- 虚假稀缺：反复说最后名额，却不断追加；无限延长限时优惠。
- 无法证明的案例：没有真实来源、结果不可核验、夸大收益或疗效。
- 误导价格锚定：虚高原价、用赠品价值凑总价、市场对比不真实。
- 模糊退款/售后：只说有保障，不说规则、条件、渠道。
- 过度适配承诺：暗示所有人都适合、所有问题都能解决。

## Safer Rewrites

| 风险表达 | 更稳妥表达 |
|---|---|
| 肯定都能学会 | 课程会用分步骤、回放、讲义和作业反馈降低学习难度 |
| 一定能改善 | 课程帮助你建立判断和练习方法，实际效果与基础、练习和个体情况有关 |
| 最后一次机会 | 本期名额/赠品/优惠有明确截止，后续是否开放以实际安排为准 |
| 学完马上变专家 | 先建立入门判断能力，再通过案例练习逐步稳定 |
| 别人可以你也一定可以 | 和你情况相似的学员有过改善反馈，你可以参考他们的学习路径 |

## Case Evidence Rules

案例佐证要同时检查：

1. 相似性：身份、基础、问题、顾虑、目标是否接近目标学员。
2. 结果：是否具体，但不夸大、不绝对。
3. 路径：是否说明如何学习、练习、被辅导或应用。
4. 证据边界：截图、反馈、数据是否真实、可授权、可脱敏。
5. 行动收口：案例后是否回到低阻力下一步，而不是直接承诺复制结果。

## Scarcity Truthfulness

稀缺必须有可解释理由：

- 服务容量：老师、助教、作业批改、答疑时间有限。
- 班期边界：开班时间、排课节奏、社群周期有限。
- 资格边界：只适合完成前置课、满足条件或适配人群。
- 权益边界：赠品、优惠、线下席位、诊断名额有限。

如果稀缺理由不能被解释，诊断为“稀缺理由不足”，不要称为“稀缺感强”。

## Refund and Guarantee

降低顾虑可以承诺服务机制、学习支持、答疑陪跑、平台规则内售后，但不要替用户编造退款条件。资料缺失时写：

```text
售后/退款规则暂缺，无法判断这一顾虑是否被真正处理。
```

## Final Compliance Check

Formal diagnosis or rewrite should include a short compliance note when:

- 涉及健康改善、医疗相关、职业收益、投资收益、证书就业。
- 有“保证、一定、包、根治、稳赚、翻倍、最后机会”等高风险词。
- 使用了真实学员案例、截图、反馈、收益或疗效表达。
- 稀缺和价格优惠是主要转化动力。
