# 课程七段与销讲八段的衔接

## Core Rule

不要把销讲转化当成课程七段里的“第八段”。课程七段和销讲八段解决的是两条不同链路：

```text
课程七段：听懂、学会、记住、愿意练习
销讲八段：相信、觉得值、敢买、现在行动
```

当用户提供的是一整节课，先判断教学主链是否完整，再单独切出销讲段判断转化链。两者可以衔接，但不应混成一个结构。

## When Embedded in a Course

Use this sequence:

1. 划分教学段和销讲段：找出教学结束、总结回顾、结尾升华、产品承接开始的位置。
2. 先判断教学是否给到 S0 教学获得：学员是否觉得刚才内容有用。
3. 再判断销讲问题唤醒是否承接 S0：是否从刚才教学自然转到共性问题。
4. 不把福利、作业、明日预告、报名播报直接当成新课程模块；按功能归入课程七段或销讲八段。
5. 如果用户只问教学结构，用课程七段；如果用户问报名、成交、优惠、价格、顾虑、案例，用销讲八段。

## Handoff Check

好的教学到销讲衔接应满足：

| 衔接点 | 检查问题 | 好信号 | 坏信号 |
|---|---|---|---|
| 总结回顾 -> 问题唤醒 | 是否从刚才学到的内容中抽出共性难题 | “刚才你会了一个动作，但真正难的是...” | “接下来给大家介绍我们的课” |
| 结尾升华 -> 方案承接 | 是否先给正确方向，而不是突然卖课 | “想把效果做稳，需要系统判断能力” | “所以一定要买进阶班” |
| 作业/练习 -> 价值塑造 | 是否把学习难点连接到课程价值 | “练的时候会卡在三类问题，后续课会分别带你解决” | “我们课程内容很多很全” |
| 下一步行动 -> 优惠政策 | 行动指令是否清楚 | “点链接提交，助教登记赠品” | “想学的自己找一下” |

## Combined Diagnosis Output

When a full course includes a sales section, use this compact combined output:

```text
一、教学主链结论
- 七段中最影响交付效果的点：
- 教学是否足以支撑销讲 S0：

二、销讲链路结论
- 销讲八段中最影响转化的点：
- 价格档位和转化目标是否匹配：

三、关键衔接问题
- 教学获得如何过渡到共性问题：
- 销讲是否破坏教学信任：

四、优先改稿动作
1.
2.
3.
```

## Red Flags

- 教学还没完成获得感，就开始报价格。
- 结尾升华变成硬广，破坏老师可信度。
- 把课程七段里的“案例应用/实操演示”误判成销讲的“案例佐证”。
- 把销讲里的“案例佐证”误判成教学案例。教学案例帮助理解和应用，销讲案例推动信任和行动。
- 为了转化过度制造焦虑，反而损害下一日到课、作业和长期信任。
