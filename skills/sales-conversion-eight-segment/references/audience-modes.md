# Audience Modes

## Core Rule

同一份诊断给不同对象看，表达方式不同。课程顾问需要决策抓手，教研需要结构证据，讲师需要可讲、可排练、保留自尊和风格的改法。

## Reader Presets

| 读者 | 输出重点 | 语气 | 避免 |
|---|---|---|---|
| 课程顾问 | 成交目标、瓶颈、价格/offer 问题、下一步补资料 | 直接、短、能推进决策 | 大篇理论解释 |
| 教研 | 八段识别、二级/三级缺口、结构误判、改稿逻辑 | 严谨、证据化、可复盘 | 只给结论不举证 |
| 讲师 | 保留什么、哪里改、怎么说、怎么排练 | 保护表达风格，具体到话术动作 | 用“你讲得不行”式评价 |
| 自己复盘 | 最短结论、得分、最大短板、先改一处 | 简明、优先级清楚 | 同时给太多方向 |
| 客户/外部协作 | 结论清楚、措辞稳、少内部术语 | 专业、克制、可执行 | 暴露内部评分争议 |

## Consultant Output

```text
结论：
当前最影响成交的瓶颈：
价格档位与转化目标是否匹配：
优先补充资料：
下一版先改：
```

## Teaching-Research Output

```text
八段结构识别：
关键二级任务缺口：
三级验收未通过：
不能升档规则：
改稿逻辑：
```

## Teacher Output

```text
建议保留：
建议调整：
新增话术：
排练提醒：
不要这样讲：
```

Teacher-facing feedback should translate structural critique into learner impact:

| 不要说 | 改成 |
|---|---|
| 你这里卖得太硬 | 学员还没先认可方向，直接听到课程名会产生销售抗拒 |
| 你这里讲得乱 | 这几句分别在讲价格、赠品和顾虑，建议拆成三个清楚段落 |
| 这个案例没用 | 这个案例缺少和学员相似的起点，建议补“他一开始也担心什么” |

## Output Length Defaults

| 场景 | 默认长度 |
|---|---|
| 用户说快速/先看 | 结论 + 3 个问题 + 3 个动作 |
| 用户给完整逐字稿 | 先做结构地图，再给核心诊断 |
| 用户要评分 | 必须包含总分、锚点、不能更高、升档任务 |
| 用户要给讲师看 | 少理论，多保留/调整/话术/排练 |
| 用户要改稿 | 直接给可讲版本，再做关键句拆解 |
