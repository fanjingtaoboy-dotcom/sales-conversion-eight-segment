# 学员转化分析

## Core Rule

销讲转化的每一段都依赖学员分析。销讲不是对所有人重复报价，而是对某一类已经听过课、已经产生一定信任和兴趣的学员，完成从“觉得有用”到“愿意购买”的推进。

资料不足时，可以从原稿推断，但必须标注“推断”。不要把推断当事实，也不要在学员画像模糊时做强判断。

## 学员转化分析卡

正式诊断、评分、改稿前，先建立这张卡：

```text
目标学员是谁：
学员刚刚听完什么教学内容：
学员当前心理状态是获得感、观望、心动、犹豫还是抗拒：
学员已经相信了什么：
学员还没有相信什么：
大多数目标学员共同存在的问题是什么：
表层问题背后的深层需求是什么：
学员容易认可的正确方案/正确道理是什么：
要卖的课程产品如何承接这个正确方案：
课程价格属于几十元、几百元、几千元、几万元哪一档：
本场转化目标是全款购买、定金锁单、加微信咨询、预约诊断还是进入社群：
学员不行动的主要阻力是什么：
可以用于案例佐证的成功案例有哪些：
这些判断来自用户提供资料，还是从原稿推断：
```

## 资料与八段对应关系

| 学员资料 | 影响的结构环节 | 检查重点 |
|---|---|---|
| 共同问题 | 问题唤醒 | 是否击中大多数目标学员，而不是个别问题 |
| 学员已有认知 | 方案承接 | 是否先说学员容易认可的正确道理，降低产品抗拒 |
| 课程解决能力 | 价值塑造 | 价值点是否一一对应学员具体问题 |
| 机会边界 | 制造稀缺 | 稀缺是否真实可信，是否调动机会感 |
| 价格体系 | 报出价格 | 是否按价格锚定、原始价格、优惠价格推进 |
| 赠品权益 | 优惠政策 | 是否讲清额外福利、赠品、权益和报名步骤 |
| 主要顾虑 | 降低顾虑 | 是否处理学不会、听不懂、没用、售后等担心 |
| 成功案例 | 案例佐证 | 是否展示结果、相似性、从众效应和情绪感染 |

## 缺少学员分析造成的典型问题

1. 问题唤醒小众：只击中少数学员，大多数人觉得和自己无关。
2. 方案承接太硬：直接说“你需要这个课”，学员产生销售抗拒。
3. 价值塑造空泛：只介绍课程内容，没有说明能解决学员哪些具体问题。
4. 稀缺虚弱：课程看起来随时都能买，学员没有现在决策的必要。
5. 报价突兀：没有价格锚定，学员只盯着优惠价贵不贵。
6. 优惠政策混乱：赠品、权益、报名路径讲不清，学员行动负担增加。
7. 降低顾虑不足：学员心动但担心学不会、听不懂、没用，最终拖延。
8. 案例佐证无效：案例不相似、没结果、没过程，不能产生“我也可以”的判断。

## 推断标注规则

Use one of these evidence labels in formal outputs:

| 标签 | 含义 | 用法 |
|---|---|---|
| 用户提供 | 用户明确给出的信息 | 可以作为正式判断依据 |
| 原稿证据 | 销讲话术、课件、逐字稿中可观察到的信息 | 可以引用短句或概括位置 |
| 合理推断 | 由课程主题、产品价格、话术重心推出来的信息 | 必须标注不确定 |
| 暂缺 | 资料不足，无法判断 | 不做强结论，列入补充清单 |

## 用户输入模板

当用户问需要提供什么资料，给这个模板：

```text
课程主题：
目标学员：
刚刚交付的教学内容：
销售产品/课程：
课程价格：
优惠政策：
赠品/权益：
转化目标：全款 / 定金 / 咨询 / 预约 / 入群
直播/课程场景：训练营单课 / 交付课 / 公开课 / 专题课
学员当前状态：获得感 / 观望 / 心动 / 犹豫 / 抗拒
学员主要顾虑：
成功案例素材：
报名路径：
合规限制：
已有材料：大纲 / PPT / 逐字稿 / 录音转写 / 其他
希望输出：快速诊断 / 完整诊断 / 评分 / 重构方案 / 优化话术 / 新销讲框架
```

## Question Priority

If only 3 questions can be asked, prioritize:

1. 这场销讲要卖什么，价格是多少，目标是全款、定金、咨询还是预约？
2. 学员刚刚听完什么教学内容，当前最可能相信什么、还担心什么？
3. 目标学员的共同问题是什么，有哪些真实案例或可证明结果？
