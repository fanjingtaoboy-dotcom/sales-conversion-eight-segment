# 改稿模式库

## Core Rule

改稿不能只把语言写得更热闹。每一句关键话术都要修复一个结构任务，推动一个购买心理变化，并尽量保留原稿里可用的老师风格、案例、互动和信任资产。

## Segment Rewrite Patterns

| 结构段 | 改写目标 | 句式骨架 |
|---|---|---|
| 问题唤醒 | 从教学获得转到共性问题 | “刚才大家学会了 X，但真正影响结果的，往往不是 X，而是 Y。” |
| 方案承接 | 先让学员认同正确方向 | “所以要解决 Y，第一步不是马上做 A，而是先建立 B。” |
| 价值塑造 | 把课程价值对应具体问题 | “这套课不是单纯教 X，而是帮你解决 1、2、3 三个问题。” |
| 制造稀缺 | 给真实机会边界 | “这次不是长期开放，因为 X 有服务容量/班期/权益边界。” |
| 报出价格 | 建立价格接受链 | “如果单独获得 X 通常要 Y；这套课正常价是 A；今天给到 B。” |
| 优惠政策 | 讲清额外权益和行动路径 | “今天报名还会额外得到 X，它帮你解决 Y；报名后通过 Z 领取。” |
| 降低顾虑 | 用机制处理担心 | “如果你担心 X，课程里有 Y 机制；但 Z 需要你配合练习。” |
| 案例佐证 | 用相似路径推动行动 | “上一期有位和你情况很像的学员，起点是 X，跟着 Y 做，最后得到 Z。” |

## Before/After Requirements

When rewriting from an existing manuscript, output:

```text
原稿问题：
改写目标：
保留素材：
删除/弱化素材：
新增素材：

改写版：

关键句拆解：
| 关键句 | 对应结构段 | 修复任务 | 心理推进 |
|---|---|---|---|
```

## Preservation Rules

Before cutting material, identify what should be preserved:

- 已经产生获得感的教学承接。
- 老师可信的专业解释。
- 学员真实评论、互动和疑问。
- 合法、真实、可脱敏的案例素材。
- 清楚的价格、权益、报名步骤。
- 有温度但不过度承诺的老师表达。

## Delete or Compress

Usually delete or compress:

- 重复催促、重复喊名额、重复报优惠价。
- 没有作用说明的赠品堆叠。
- 与目标学员无关的小众问题。
- 只让老师自我感动、不能服务学员判断的情怀段落。
- 没有证据和边界的绝对承诺。
- 不能连接购买判断的随机答疑。

## Action Closing Patterns

低价产品：

```text
现在点下方链接，提交后就能锁定今天权益，助教会按报名顺序发放资料。
```

中价课程：

```text
如果你刚才听完已经发现自己卡在这个问题上，现在报名最核心不是买一堆课，而是进入一个有人带你练、有人提醒、有人纠偏的学习周期。
```

高价课程：

```text
这类项目不建议所有人直接下单。更稳妥的方式是先预约一次诊断，确认你的基础、目标和时间投入是否适合，再决定要不要进入正式班。
```

## Mapping After Rewrite

Every polished rewrite should be followed by a mapping table:

| 优化话术关键句 | 对应结构段 | 修复的二级任务 | 学员心理变化 |
|---|---|---|---|
| “不是不会做，而是不知道什么时候该做” | 问题唤醒 | 呈现共性问题 | 从觉得有用到觉得相关 |
| “要把效果做稳，先建立判断顺序” | 方案承接 | 提出正确道理 | 从抗拒课程到认可方向 |
| “课程每天解决一个场景，并有作业提醒” | 价值塑造 | 说明解决路径 | 从方向认可到价值确认 |
| “名额受作业批改和答疑容量限制” | 制造稀缺 | 解释稀缺理由 | 从有价值到机会紧迫 |
| “正常价 A，今天训练营价 B” | 报出价格 | 原始价格、优惠价格 | 从只看贵不贵到理解划算 |
| “赠品 X 帮你课后复盘” | 优惠政策 | 说明赠品作用 | 从知道价格到权益清晰 |
| “有回放、讲义和答疑，但需要跟练” | 降低顾虑 | 承诺与边界 | 从担心到愿意尝试 |
| “相似学员从 X 到 Y 的路径” | 案例佐证 | 结果、路径、从众 | 从犹豫到行动信心 |
