## 核心定位

销讲转化八段用于判断线上课程教学之后的销讲话术结构是否完整、每一段是否承担了正确转化功能，以及后续应该如何调整。

它不是广告结构，也不是教学结构，而是教学之后的成交承接结构：

```text
广告五段：陌生用户要不要停下来看、要不要了解
课程七段：学员能不能听懂、学会、记住并愿意练习
销讲八段：已听课学员是否相信、觉得值、敢买、现在行动
```

检查销讲结构时，不只看“有没有这一段”，还要看“这一段是否真正完成了购买心理推进任务”。

## 八段总结构

```text
问题唤醒 -> 方案承接 -> 价值塑造 -> 制造稀缺 -> 报出价格 -> 优惠政策 -> 降低顾虑 -> 案例佐证
```

| 顺序 | 模块名称 | 学员心理变化 | 核心作用 |
|---|---|---|---|
| 1 | 问题唤醒 | 从“刚才内容有用”到“大多数目标学员都有这个共性问题” | 用高相关问题唤醒更多目标学员，而不是只击中个别人 |
| 2 | 方案承接 | 从“我有问题”到“我认可这个正确解决方向” | 先承接学员容易接受的正确道理/方案，再过渡到课程产品 |
| 3 | 价值塑造 | 从“方向对”到“这个课程能解决我的具体问题” | 把课程价值点和学员问题一一对应，证明能解决问题 |
| 4 | 制造稀缺 | 从“有价值”到“这个机会不容易随时获得” | 调动机会感和紧迫感，避免学员觉得随时都能买 |
| 5 | 报出价格 | 从“想了解”到“价格有参照、原价也划算、优惠价更划算” | 通过价格锚定、原始价格、优惠价格建立价格接受度 |
| 6 | 优惠政策 | 从“知道价格”到“知道额外得到什么、怎么报名” | 说明额外福利、赠品、权益、报名步骤和指令 |
| 7 | 降低顾虑 | 从“想买但担心”到“主要顾虑被处理” | 打消学不会、听不懂、有没有用、售后保障等购买阻力 |
| 8 | 案例佐证 | 从“仍在犹豫”到“别人能成功，我也可以” | 用成功案例、结果展示、从众效应和情绪感染推动行动 |

## 底层心理推进

```text
S0 教学获得：学员觉得刚才内容有用
S1 共性相关：意识到这不是个别问题，而是大多数目标学员都会遇到的问题
S2 方案认同：先接受一个低抗拒的正确方向、正确道理或正确解决原则
S3 价值确认：看到课程/产品如何对应解决自己的具体问题
S4 机会紧迫：意识到这个机会不是随时、随地、无限量都有
S5 价格接受：先接受价格锚点，再接受原始价格和优惠价格
S6 权益清晰：知道额外福利、赠品、权益、报名步骤和指令
S7 顾虑降低：学不会、听不懂、没用、售后等阻力被处理
S8 信任行动：通过案例看到别人已成功，产生从众和行动意愿
```

## 说服力变量映射

```text
问题唤醒 = 相关力 R + 共性问题唤醒
方案承接 = 价值力 V 的低抗拒入口
价值塑造 = 价值力 V 强化
制造稀缺 = 行动力 A + 情绪紧迫
报出价格 = 价值力 V + 价格接受
优惠政策 = 行动力 A + 权益增强
降低顾虑 = 阻力 F 降低
案例佐证 = 信任力 T + 从众行动
```

`R/V/T/A/F` 的中文含义是：相关力、价值力、信任力、行动力、阻力。

## 使用原则

1. 八段结构是功能链路，不是固定播稿模板。实际使用时可以根据价格、信任基础、转化目标和直播节奏调整篇幅。
2. 问题唤醒必须追求广泛相关。它要唤醒大多数目标学员，而不是围绕个别人的小众问题展开。
3. 方案承接不能一上来就说“你需要买这个课程”。应先提出学员容易认可的正确方向、正确道理或正确方案，再把课程作为承接工具。
4. 价值塑造不是单纯介绍课程是什么，而是证明课程能解决哪些具体问题。每个价值点都要对应学员的某个问题或顾虑。
5. 制造稀缺要放在价值塑造之后、价格之前。先让学员觉得有价值，再让学员感觉机会不容易随时获得。
6. 报出价格不是直接报最终价格，而是先做价格锚定，再报原始价格，再报优惠价格。
7. 优惠政策负责说明正式课程之外的额外福利、赠品、权益、报名步骤和行动指令。
8. 降低顾虑负责打消学员购买前的真实担心，例如学不学得会、听不听得懂、有没有用、售后保障等。
9. 案例佐证是固定一级模块。它不仅证明可信，还要展示结果、制造从众效应、以情动人，让学员产生“别人可以，我也可以”的判断。
10. 健康、教育、金融等高敏感品类必须先合规，后转化。不能用绝对承诺、恐吓焦虑、虚假稀缺或无法证明的案例强推成交。

## 结构原理层

诊断和改稿时，先抽象到结构原理，再处理具体案例。

```text
原理：这段为什么必须存在，推动什么心理变化
原则：什么情况算完成，什么情况算误判
方法：怎样设计、改稿、追问和验收
案例：某个行业或课程中的具体表现
```

核心检查：

1. 功能优先：先看每段是否完成心理转换，再看内容是否热闹。
2. 共识优先：前两段应从学员已认可或容易认可的事情进入。
3. 递进收口：问题要从广泛相关逐步收束到本场关键购买判断。
4. 先标准后产品：方案承接先讲正确标准，再证明产品符合标准。
5. 价值下沉：课程模块要下沉到问题、机制和结果感，而不是只列目录。
6. 主张成链：强卖点必须拆成连续因果，不能从能力直接跳到结果。
7. 主次分明：多类人群可以覆盖，但主目标人群决定主线。
8. 证据有界：案例、反馈、老师经验和机制演示要分层使用，不能互相替代。

## 二级任务总表

| 一级模块 | 二级任务 | 话术落点 |
|---|---|---|
| 问题唤醒 | 承接刚才教学；锁定大多数目标学员；呈现共性问题；放大相关性；留下方案入口 | 让大多数学员从“刚才有用”走到“这问题和我有关，需要解决” |
| 方案承接 | 避免直接推产品；提出正确道理；解释正确方案；让学员先认同方向；再引出课程承接 | 让学员从“我有问题”走到“这个正确方案我认可” |
| 价值塑造 | 对应具体问题；拆解核心价值点；说明解决路径；解释价值点如何发挥作用；强化结果感 | 让学员知道课程能帮我解决哪些问题、为什么有用 |
| 制造稀缺 | 给出机会边界；解释稀缺理由；制造获得不易；调动情绪；避免虚假稀缺 | 让学员觉得这个机会不是随时随地都能买 |
| 报出价格 | 价格锚定；报原始价格；证明原价划算；报优惠价格；完成价格接受 | 让学员觉得原价合理，优惠价更值得 |
| 优惠政策 | 说明额外福利；说明赠品权益；说明领取条件；说明报名步骤；给出行动指令 | 让学员知道除了课程还得到什么，以及怎么报名 |
| 降低顾虑 | 识别购买顾虑；回应学习难度；回应效果担心；说明售后保障；给出承诺与边界 | 让学员从“想买但担心”走到“顾虑被处理” |
| 案例佐证 | 选择相似案例；展示成功结果；讲清成功路径；制造从众效应；以情动人；回到行动 | 让学员从“别人能成功”走到“我也可以行动” |

## 关键边界判断

| 边界 | 前一段回答 | 后一段回答 | 常见断裂 |
|---|---|---|---|
| 问题唤醒 / 方案承接 | 这个共性问题是否和大多数目标学员有关 | 解决这个问题，学员容易认可的正确方向是什么 | 从问题直接跳到课程产品 |
| 方案承接 / 价值塑造 | 为什么需要这个正确方向 | 课程产品如何把这个方向落地，并解决具体问题 | 课程价值像硬推销 |
| 价值塑造 / 制造稀缺 | 这个课程为什么有用 | 这个有用的机会为什么不是随时都有 | 没价值就稀缺，像逼单 |
| 制造稀缺 / 报出价格 | 机会为什么有限 | 这个有限机会原来值多少钱，现在多少钱 | 价格突然出现，学员只问贵不贵 |
| 报出价格 / 优惠政策 | 价格锚定、原始价格、优惠价格是什么 | 除了课程本身，还有哪些额外福利、赠品、权益和报名指令 | 价格和赠品混在一起，学员听乱 |
| 降低顾虑 / 案例佐证 | 我的担心有没有被具体处理 | 有没有和我相似的人已经成功，从而让我更敢行动 | 用随机案例替代保障和边界 |

## 八段结构咬合检查

| 咬合位置 | 检查问题 | 常见断裂 |
|---|---|---|
| 问题唤醒 -> 方案承接 | 是否从共性问题自然进入正确方向 | 直接从问题跳到课程产品 |
| 方案承接 -> 价值塑造 | 是否先让学员认可方向，再证明课程价值 | 课程价值像硬推销 |
| 价值塑造 -> 制造稀缺 | 是否先证明有用，再说明机会有限 | 没价值就稀缺，像逼单 |
| 制造稀缺 -> 报出价格 | 是否先制造机会感，再进入价格接受 | 价格突然出现，学员只问贵不贵 |
| 报出价格 -> 优惠政策 | 是否先完成价格锚定，再讲额外权益 | 价格和赠品混在一起，学员听乱 |
| 优惠政策 -> 降低顾虑 | 优惠后是否处理购买担心 | 学员觉得划算但不敢买 |
| 降低顾虑 -> 案例佐证 | 顾虑处理后是否用案例强化信任和行动 | 案例随机，无法收口 |

## 非主线内容归位

销讲里的赠品、答疑、互动、助教提醒、倒计时、报名播报，不能随意变成新的一级模块。它们必须按功能归位。

| 内容类型 | 归位规则 | 检查重点 |
|---|---|---|
| 赠品福利 | 归入优惠政策 | 是否增加权益感，是否讲清领取条件 |
| 答疑 | 主要归入降低顾虑 | 是否处理真实顾虑，而不是随机聊天 |
| 互动 | 归入对应心理推进段 | 是否确认相关性、方案认同、价值判断、行动状态 |
| 助教发链接 | 归入优惠政策或降低顾虑 | 是否说明报名步骤和操作指令 |
| 倒计时/剩余名额 | 归入制造稀缺 | 是否有可信稀缺理由 |
| 报名播报 | 归入案例佐证或制造稀缺 | 是否增强从众信任或提醒机会变化 |
| 老师情怀 | 视功能归入价值塑造或案例佐证 | 是否服务学员价值，而不是自我感动 |
