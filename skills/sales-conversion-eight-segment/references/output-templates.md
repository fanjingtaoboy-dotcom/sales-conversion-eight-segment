# 输出模板

## Intake Gate

Use when key prerequisites are missing.

```text
我可以先基于现有材料做暂判；但如果要【正式评分/完整改稿/给讲师使用】，还差这几个关键前提：

1. 这场销讲要卖什么，价格是多少？
2. 转化目标是什么：全款、定金、加微信、预约诊断、进群、续报还是升单？
3. 目标学员是谁，刚刚听完什么教学内容？
4. 学员此刻已经相信什么、还没有相信什么？
5. 学员不行动的最大阻力是什么？

你先补这几项，我就能给更稳的判断。
```

## New Conversion Framework

Use when the user asks to design a sales section from scratch.

```text
前置判断：
- 学员刚刚获得了什么：
- 要卖什么：
- 价格档位：
- 转化目标：
- 最大阻力：

八段销讲框架：
1. 问题唤醒：用什么共性问题承接刚才教学
2. 方案承接：先让学员认可什么正确方向
3. 价值塑造：课程如何解决哪些具体问题
4. 制造稀缺：真实机会边界是什么
5. 报出价格：锚点、原价、优惠价如何推进
6. 优惠政策：赠品、权益、领取条件、报名步骤
7. 降低顾虑：要处理哪些核心顾虑
8. 案例佐证：用什么相似案例和从众证据收口

需要补充确认：
```
