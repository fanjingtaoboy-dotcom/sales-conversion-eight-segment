## Standard Diagnosis Report

Use for most script or transcript diagnosis.

```text
一、素材基础信息
二、学员转化分析卡
三、八段结构识别表
四、逐段诊断
五、主要问题深拆
六、价格决策难度判断
七、优化方向
八、优化话术或结构重构
九、优化稿拆解
十、资料补充清单
```

## New Conversion Framework

Use when the user asks to design a sales section from scratch.

```text
前置判断：
- 学员刚刚获得了什么：
- 要卖什么：
- 价格档位：
- 转化目标：
- 最大阻力：

八段销讲框架：
1. 问题唤醒：用什么共性问题承接刚才教学
2. 方案承接：先让学员认可什么正确方向
3. 价值塑造：课程如何解决哪些具体问题
4. 制造稀缺：真实机会边界是什么
5. 报出价格：锚点、原价、优惠价如何推进
6. 优惠政策：赠品、权益、领取条件、报名步骤
7. 降低顾虑：要处理哪些核心顾虑
8. 案例佐证：用什么相似案例和从众证据收口

需要补充确认：
```

```text
1.
2.

排练时重点检查：

2. 是否先讲正确方案再讲课程

4. 顾虑是否有机制
5. 案例是否相似、有结果、有路径
```
