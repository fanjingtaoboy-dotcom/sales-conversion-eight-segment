# 0元表单到高客单课程转化

## Core Rule

0元表单、免费营、结缘营、福利课和低价体验用户，不等于高信任用户。即使学员已经听过课、做过动作、有过获得感，也通常只是完成了低承诺体验；当目标产品接近 3000 元或进入几千元系统班时，要先诊断“低承诺体验 -> 高信任购买”的桥是否搭好。

Do not score these scripts like low-ticket welfare lessons. The key question is not only whether the eight segments appear, but whether they collectively answer:

```text
我为什么需要系统学？
为什么是现在？
为什么是这个老师/团队？
为什么值几千元？
为什么我能学、敢买、出了问题有人管？
```

## Lead Warmth Card

Use this card before diagnosis, scoring, or rewriting:

```text
入口来源：0元表单 / 免费营 / 结缘营 / 福利课 / 低价体验 / 老学员 / 转介绍
免费体验深度：听课天数、作业提交、实操反馈、群互动、是否加微信、是否领资料
刚获得的价值：一个动作、一个判断方法、一次体验结果、一次老师反馈、一次同伴见证
已相信什么：老师专业、方法有用、课程认真、自己有问题、系统学习有必要
还没相信什么：近3000元/几千元是否值、自己是否适合、是否能跟上、售后是否可信
最大阻力：价格、时间、家人意见、年龄/基础、手机/支付操作、健康效果边界、被销售警惕
本场转化目标：全款 / 定金 / 咨询 / 预约诊断 / 加微信 / 进系统班
```

If these fields are missing, infer cautiously from the transcript and label uncertainty. For formal scoring or full rewrite, ask for the missing fields that most affect the result.

## High-Ticket Trust Bridge

A strong free-entry high-ticket conversion usually needs this bridge:

```text
免费体验复盘 -> 问题升级 -> 系统方案 -> 服务系统 -> 价格锚定 -> 风险逆转 -> 证据矩阵 -> 低阻力行动
```

| Bridge step | Function | Failure signal |
|---|---|---|
| 免费体验复盘 | Remind learners they already received value and were accompanied | Only says "大家学得很好" without naming the value gained |
| 问题升级 | Show why one free lesson, one action, or one tip is not enough | Directly says "所以要买课" |
| 系统方案 | Convert scattered tips into a system learners can believe | Only lists modules, no learning path |
| 服务系统 | Explain teacher/assistant/feedback/offline/replay/materials | Says "服务很好" but cannot name what happens after purchase |
| 价格锚定 | Compare price to total value, service cost, long-term use, or current waste | Uses a fake high original price or pure fear |
| 风险逆转 | Clarify refund, replay, price protection, learning support, service boundaries | Says "放心有保障" without rules |
| 证据矩阵 | Provide multiple proof types, not one extreme case | Only emotional stories or vague praise |
| 低阻力行动 | Make the next step clear, reversible, or consultative enough | Only repeats "现在拍" |

## Offer-Service Stack

For near-3000-yuan and few-thousand-yuan products, evaluate whether value is carried by a service system, not only content quantity.

Check whether the script explains:

1. 主课程路径：学什么、按什么顺序学、学完能形成什么能力。
2. 老师/助教陪伴：谁答疑、多久反馈、在哪里承接。
3. 作业/实操反馈：学员做错时如何被纠偏。
4. 回放/资料/工具：帮助零基础、慢学员、缺席学员降低学习阻力。
5. 线下/直播/社群组合：不同交付形式分别解决什么问题。
6. 长期权益：回放年限、复训、保价、后续答疑等规则是否清楚。
7. 售后边界：退款、协议、服务有效期、适配人群和不适合人群。

If the script only says "内容很系统、老师很厉害、赠品很多", do not judge value shaping as complete.

## Proof Matrix

High-ticket free-entry conversion should not rely on one case. It needs a matrix that lets learners see "people like me can start, persist, get feedback, and make progress."

Recommended proof types:

| Proof type | What it proves | Notes |
|---|---|---|
| 免费营获得感 | The free experience was real, not bait | Use feedback, homework, interaction, or learner language |
| 相似学员案例 | Learners with similar age, base, problem, or worry can follow | Avoid implying identical results |
| 学习过程案例 | Progress came from practice, feedback, and service | Stronger than before/after claims alone |
| 服务承接证据 | Teacher/assistant actually respond and support | Screenshots must be authorized and anonymized |
| 多问题覆盖案例 | Product handles several common situations, not one narrow pain point | Do not overstate medical or outcome claims |
| 现场从众信号 | Others are asking, enrolling, or getting help | Useful, but cannot replace real proof |

For health or education offers, proof must include boundary language. Avoid "all learners can get this result".

## Objection Priority

For 0-yuan/free-entry learners buying near-3000-yuan or few-thousand-yuan courses, prioritize objections in this order:

1. 值不值：为什么不是免费资料、短课、单个动作就够了。
2. 敢不敢：退款、回放、服务、协议、适配边界是否清楚。
3. 能不能：零基础、年龄、时间、手机操作、听不懂、跟不上怎么办。
4. 家人/钱：如何解释价值、分期/定金/咨询承接是否存在。
5. 现在要不要：名额、班期、优惠、服务容量是否真实可信。

If the script jumps from free value directly to price/名额, it usually fails on objections 1-3.

## Price Anchoring for Free Leads

Price anchoring can use:

- system learning value: from scattered tips to repeatable judgment and practice;
- service cost: teacher time, assistant feedback, small class capacity, offline seats;
- long-term use: replays, materials, repeated practice, family/self-use scenarios;
- current waste: money/time spent on ineffective attempts, but without fear pressure;
- normal price and current policy, only when real and explainable.

Avoid anchoring mainly by fear, family guilt, medical threat, or inflated gift prices. Emotional urgency may support action, but cannot replace clear value and proof.

## Scoring Adjustments

For free-entry high-ticket scripts:

- If learner source and free-experience depth are unclear, formal scoring should mark a 资料边界.
- If there is no service-system explanation, `价值塑造` cannot be judged fully qualified.
- If refund/guarantee/support rules are vague, `降低顾虑` cannot be fully qualified.
- If proof relies on one vague or extreme case, `案例佐证` cannot be fully qualified.
- If scarcity is based on repeated "last chance" without a service-capacity or policy reason, `制造稀缺` is weak and may create trust risk.
- If health, learning, income, or life-change results are absolute, do not give 9 points even when the script feels powerful.

## Rewrite Direction

When rewriting, do not just strengthen urgency. Add the missing bridge:

```text
刚才你已经体验到一个小结果/小判断
但单点方法解决不了长期复杂问题
所以需要一套系统路径和有人纠偏
这门课由哪些内容、服务、工具和权益支撑
为什么这个价格对应的是系统交付而不是几节课
担心学不会/没时间/不适合/售后的人，分别怎么被承接
用相似案例和免费营反馈证明这条路径可参考
最后给清楚的行动方式和下一步承接
```
