# 0元表单到低客单课程转化

## Core Rule

0元表单、免费营、结缘营、福利课用户转几十元低客单课程时，不要按高客单系统班诊断。几十元产品的购买心理通常不是“重大投入是否值得”，而是：

```text
这个小钱值不值？
是不是真的有东西拿？
返还/免费规则清不清？
我会不会操作失败？
现在不抢会不会错过？
```

低客单销讲可以更快进入价格、优惠、赠品和行动，但不能只靠催单。它必须让学员明白自己刚获得了什么、继续学能拿到什么、几十元付款代表什么、如何领取权益、如何返还或售后。

## Low-Ticket Action Card

Use this card before diagnosis or rewrite:

```text
入口来源：0元表单 / 免费直播 / 免费营 / 结缘营 / 福利课 / 抽奖入口
刚获得的价值：体验动作、病症分析、方法原理、老师答疑、互动反馈
低价动作：几十元购买 / 付费占位 / 学费全返 / 领取书籍工具 / 进课 / 加微信
产品权益：课程节数、回放、讲义、书籍、工具、包邮、社群、助教答疑
价格规则：原价、现价、是否返还、返还条件、返还方式、返还时间
名额/截止：名额数、截止点、追加原因、是否课程结束关闭
行动路径：点击、填信息、提交订单、支付、发地址、加助教、进群
主要阻力：怕被骗、不会报名、是否真返、是否有用、没时间、收不到赠品
```

## Recommended Low-Ticket Chain

For tens-yuan free-lead conversion, a strong chain is:

```text
教学获得感 -> 共性小痛点 -> 低价继续学 -> 权益明细 -> 返还/赠品规则 -> 名额截止 -> 助教操作 -> 短顾虑/短案例 -> 回到教学或收尾
```

This chain can loop several times in a live room. Diagnose it as waves, not as one long continuous sales section.

| Step | Function | Failure signal |
|---|---|---|
| 教学获得感 | Use the just-delivered method or interaction as S0 trust | Sells before any value is delivered |
| 共性小痛点 | Remind learners of an urgent, broad, easy-to-act problem | Uses rare severe cases as the main trigger |
| 低价继续学 | Present the low price as a seat or learning commitment | Says "free" but hides required payment |
| 权益明细 | Show exactly what learners get now | Lists gifts without use, delivery, or conditions |
| 返还/赠品规则 | Explain full-return, shipping, task, replay, and claim rules | "学费全返" but no condition, timing, or path |
| 名额截止 | Create immediate action with a believable boundary | Repeatedly adds quota without reason |
| 助教操作 | Remove action friction step by step | Only says "click link" or "hurry up" |
| 短顾虑/短案例 | Reduce fear of being tricked, not learning, or wasting time | Uses absolute health promises or extreme cases |

## Price and Refund Rules

For low-ticket offers, the most important offer-policy checks are:

1. 付款性质：是购买、押金、占位费、学费、还是返还后免费学。
2. 返还条件：听完、打卡、作业、考试、加群、申请，还是无条件返还。
3. 返还方式：原路退回、红包、抵扣、平台退款、助教处理。
4. 返还时间：课后多久、完成任务后多久、是否有截止。
5. 赠品领取：是否需要地址、谁登记、是否包邮、什么时候发。
6. 未完成任务：不听课、不交作业、不领赠品、不加助教时如何处理。
7. 回放与服务：能看多久、如何进入课程、谁提醒、谁答疑。

If these are unclear, the offer may still convert because price is low, but `优惠政策` and `降低顾虑` cannot be judged fully qualified.

## Low-Ticket Wave Types

| Wave | Common signal | Main function | Check |
|---|---|---|---|
| 抽奖/福利预热 | 开课前送福利、抽奖、保持在线 | 留存和注意力 | 是否和后续学习相关 |
| 首轮低价报价 | 原价、几十元、赠书、赠工具 | 报价和权益 | 是否讲清低价理由 |
| 全返解释波 | 学完返还、相当于免费学 | 降低价格阻力 | 是否讲清规则 |
| 助教操作波 | 立即抢购、提交订单、支付、发地址 | 行动路径 | 是否能照着完成 |
| 名额追加波 | 抢完、再加、最后、课程结束截止 | 制造稀缺 | 是否有真实理由和边界 |
| 教学回流波 | 报名后继续讲干货或答疑 | 降低销售疲劳 | 是否回到教学价值 |
| 结尾倒计时波 | 倒数、课程结束关闭、最后领取 | 行动收口 | 是否清楚结束规则 |

## Low-Ticket Scoring Adjustments

For tens-yuan products:

- A shorter sales section can still be high quality if value, offer, refund/gift rules, and action path are clear.
- `报出价格` can appear earlier than in high-ticket sales, but must not replace problem and value.
- `案例佐证` can use short feedback, in-class体验, enrollment signals, or one simple similar story; it does not need a high-ticket proof matrix.
- If the script relies only on "便宜、抢、最后" and lacks clear value or rules, it usually cannot exceed 5.
- If it says "免费学习" while requiring payment, it must explain the payment and refund mechanism. Otherwise, flag trust risk.
- If quota repeatedly changes from limited to unlimited, diagnose wave strategy and trust risk separately.
- Health, income, certification, and treatment claims still need compliance boundaries even when price is low.

## Rewrite Direction

When improving low-ticket free-lead sales, prioritize clarity over heavier persuasion:

```text
刚才你已经体验到一个具体方法
如果想继续学完整步骤，可以用几十元先占一个学习名额
这几十元对应哪些课程、资料、工具和服务
学完如何返还、什么时候返、找谁返
报名后怎么进课、怎么领书和工具、谁联系你
不会报名的人按哪几步操作
担心学不会/没时间的人如何看回放或找助教
最后说明真实截止点，然后回到教学或收尾
```
