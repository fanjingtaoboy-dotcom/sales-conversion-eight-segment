# Skill 迭代手册

作者：范范之辈

这份手册用于持续优化 `sales-conversion-eight-segment`，让它从“能用”变成“越用越准”。

## 迭代目标

每一轮迭代至少提升下列一种能力：

1. 触发更准：用户说报名、续报、升单、成交、咨询承接时，能自动调用。
2. 判断更准：能稳定区分教学结构、销售结构、offer 问题和合规问题。
3. 评分更稳：同类稿件前后打分一致，不因情绪强弱、篇幅长短误判。
4. 改稿更能落地：不仅指出问题，还能给出讲师可直接讲的替代话术。
5. 资料要求更清楚：缺什么资料、为什么缺、补了能提升哪个判断。

## 推荐迭代循环

```text
真实案例 -> 脱敏 -> 运行 skill -> 记录输出 -> 人工校准 -> 提炼规则 -> 加入参考文件或 eval -> 校验 -> 发布
```

## 什么时候改 SKILL.md

只在这些情况改 `SKILL.md`：

1. 新增重要触发词，例如续报、升单、咨询承接。
2. 新增一个需要模型知道的任务模式。
3. 新增一个参考文件，需要告诉模型什么时候读取。
4. 当前流程顺序导致常见误判。

普通知识、细则、样例、话术模板，优先放到 `references/` 或 `evals/`。

## 什么时候改 references

适合沉淀到 `references/` 的内容：

1. 某类课的稳定判断规则。
2. 某个模块经常误判的边界。
3. 某类价格档位的权重差异。
4. 某类输出对象的表达要求。
5. 合规、安全、证据边界。

## 什么时候改 evals

适合沉淀到 `evals/` 的内容：

1. 人工已校准的典型 1/3/5/7/9 分案例。
2. 容易误判的边界案例。
3. 高客单目标不匹配案例。
4. 教学和销讲混在一起的逐字稿案例。
5. 合规风险案例。
6. 输出对象不同导致表达要求不同的案例。

## 下一批最值得补的资料

优先级从高到低：

1. 3-5 份脱敏销讲逐字稿，覆盖不同讲师和不同价格档位。
2. 每份稿件的人工评分、不能升档原因、最想保留的讲师表达。
3. 真实产品 offer 信息：价格、优惠、赠品、服务、售后、行动路径。
4. 真实案例素材的脱敏版本：起点、过程、结果、证据边界。
5. 讲师实际能接受的反馈口径：哪些话太重，哪些话能推动改稿。
